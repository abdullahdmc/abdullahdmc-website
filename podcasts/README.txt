PODCAST INBOX: how to publish an episode on abdullahdmc.com
============================================================

1. Make the episode in Gemini Notebook (Audio Overview) from your AI in Health Research roundups.
2. Download the audio and save it into the "inbox" folder next to this file.
3. That's all. The daily website task (around 11:08, or when you next open the Claude app)
   uploads it, creates the podcast post, and moves the file to "published".

FILE NAME
---------
    YYYY-MM-DD Episode title.mp3

    Examples:
    2026-10-29 LLM diagnostic agents vs physicians.mp3
    2026-11-05 AI triage in primary care.m4a
    2026-11-12.mp3                         (no title: one is written from the roundups)

  - Date first, as year-month-day. It becomes the post date, and the episode is linked to the
    AI roundups published since the previous episode, up to this date.
  - The title is optional. Keep it short; letters, numbers, spaces, hyphens and colons are fine
    (use " - " instead of ":" if Windows complains).
  - Audio types: .mp3 (best), .m4a, .wav, .ogg.

OPTIONAL NOTES FILE
-------------------
    Put a text file with the same name next to the audio, e.g.
    2026-10-29 LLM diagnostic agents vs physicians.txt
  - First line: a one- or two-sentence description shown under the player.
  - Further lines (optional): any links you want listed, one per line.

If something goes wrong (for example the file is too large for the website), the file stays in
"inbox" and the task tells you why.
